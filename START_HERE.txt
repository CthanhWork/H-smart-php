## 🎯 ANH CHỈ CẦN LÀM 3 THỨ

### ✅ Bước 1: Chuẩn bị (5 phút)

**GitHub Token** - Vào đây: https://github.com/settings/tokens
- Click "Generate new token (classic)"
- Chọn scopes: `repo`, `admin:repo_hook`
- Copy token (ví dụ: `ghp_xxxxxxxxxxxxx`)

**Docker Hub Account** - Vào đây: https://hub.docker.com
- Chưa có? Tạo nhanh (free)
- Nhớ username

### ✅ Bước 2: Chạy 1 lệnh (20 phút)

Mở PowerShell, cd tới `D:\H-smart-php`, rồi copy-paste:

```powershell
.\DEPLOY_ALL_IN_ONE.ps1 -GitToken "ghp_YOUR_TOKEN_HERE" -DockerUser "your_docker_username"
```

**Thay 2 giá trị:**
- `ghp_YOUR_TOKEN_HERE` ← Token từ bước 1
- `your_docker_username` ← Docker Hub username từ bước 1

**Rồi Enter. Xong!** ✨
